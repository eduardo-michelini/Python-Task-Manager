# Python-Task-Manager

A simple and practical CLI Task Manager made with Python. You can manage your daily tasks, view pending and completed items, and mark tasks as done in real time. Enjoy!

Explanation:

1. Setup: Asks for your username and initializes empty lists for pending and completed tasks.
2. Loop: Keeps the program running through a menu until you choose option 5 to exit.
3. Task Creation: Allows you to enter new tasks and adds them to the pending list.
4. Status Tracking: Lets you view lists of pending and completed tasks separately at any time.
5. Completion: Moves tasks from the pending list to the completed list seamlessly.

# Python-Gerenciador-De-Tarefas

Um gerenciador de tarefas simples e prático via terminal feito em Python. Você pode organizar suas tarefas diárias, visualizar itens pendentes e concluídos, e marcar tarefas como feitas em tempo real. Aproveite!

Explicação:

1. Setup: Pede o seu nome de usuário e cria as listas vazias para tarefas pendentes e concluídas.
2. Loop: Mantém o programa rodando através de um menu até que você escolha a opção 5 para sair.
3. Criação de Tarefas: Permite inserir novas tarefas e as adiciona à lista de pendentes.
4. Acompanhamento: Permite visualizar as listas de tarefas pendentes e concluídas separadamente a qualquer momento.
5. Conclusão: Move as tarefas da lista de pendentes para a de concluídas de forma simples.
